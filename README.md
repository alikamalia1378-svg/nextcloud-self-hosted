# Nextcloud Self-Hosted

Self-hosted cloud storage solution using Nextcloud, Docker, Docker Compose and MariaDB on Ubuntu.

## Technologies

- Ubuntu
- Docker
- Docker Compose
- Nextcloud
- MariaDB

## Architecture

The application consists of two main containers:

- Nextcloud: cloud storage and web application
- MariaDB: database backend

## Features

- Self-hosted cloud storage
- File synchronization
- Multi-device access
- Docker-based deployment
- MariaDB database
- Network troubleshooting and connectivity testing
